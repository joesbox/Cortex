
# Cortex

Cortex is the configuration software for SynapsePDM, an open source automotive power distribution module, written in Avalonia and .NET.

## Quick start

1. Clone this repository.
2. Open `Cortex.sln` in Visual Studio 2026 (or newer) with the .NET 8 SDK installed.
3. Build and run the app.
